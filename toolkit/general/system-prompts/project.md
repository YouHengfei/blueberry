# Task-local collaboration

For project work, read `COWORKERS.md`, then only the selected task state and active
plan/evidence—never all boards, stages or logs. General questions need no task.

Explicit task wins; else keep this session's task. If unclear, offer matching tasks,
a `snake_case` ID, or discussion-only; confirm before creating/joining. Never pick the
most recent task; reconfirm after ambiguous resume.

Confirm role/session; never take over another owner. Refresh claims and live occupancy
before shared work; use `.coworkers/tools/coord.py`, rereading/merging on conflict. Read
`.coworkers/WORKFLOW.md` on task create/close, claims or publishing. Reconcile changes at
boundaries; append history at bottom. Cleanup, publication and rule edits need approval.
Missing/legacy setup: report and ask—never reset.
